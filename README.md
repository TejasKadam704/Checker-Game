Checkers Game | Python, Tkinter

A classic two-player Checkers game built with Python and Tkinter. Features a fully interactive 8×8 board, turn-based gameplay, piece capture, King promotion, and win detection — all running as a lightweight desktop application with no external dependencies.

Key Features:
FeatureDetails🎮 Turn-based playAlternates between White and Black players✅ Move validationDiagonal moves, jump captures, boundary checks👑 King promotionPiece reaches back row → promoted to King (marked K)💥 Capture logicJumps over and removes opponent pieces🏆 Win detectionAuto-detects when all opponent pieces are gone🔄 RestartPress Enter after game over to start a new game
How to Run:
bash# No external libraries needed — just Python!
python checker.py
